Welcome to Chapter 5

Cascading Style Sheets, commonly known as CSS, is used to control the appearance and presentation of HTML webpages.

In this chapter, we will learn about typography, consistency, different types of CSS styles, and the use of images in web design.

5.1 Typography

Typography refers to the design and arrangement of text on a webpage. Good typography improves readability and helps users understand information.

Important Typography Properties

CSS can control font family, font size, font weight, text colour, line height, text alignment and letter spacing.

5.2 Consistency

Consistency means using similar design elements throughout a website. This includes colours, typography, navigation, spacing, buttons and page layouts.

Examples of Consistent Design

  • Use the same navigation structure.
  • Use consistent colours.
  • Use consistent heading styles.
  • Use consistent spacing.
  • Use consistent button designs.

5.3 Types of Styles

CSS can be applied to HTML using inline, internal or external styles.

Internal CSS

Internal CSS is normally written inside a <style> element in the HTML document.

External CSS

External CSS is stored in a separate CSS file. This webpage uses an external stylesheet named style.css.

5.4 Imaging for Web Design

Images are commonly used in websites to communicate information, support visual storytelling and improve the presentation of content.

Example Web Image

The image above uses the CSS class responsive-image. The image automatically adjusts to the available screen width.

Common Image Formats

  • JPEG - commonly used for photographs.
  • PNG - useful for graphics and transparency.
  • GIF - commonly used for simple animations.
  • SVG - useful for logos and vector graphics.
  • WebP - modern format suitable for web images.
  • AVIF - modern format with efficient compression.
